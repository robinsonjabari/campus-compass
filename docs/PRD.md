# Campus Compass - Product Requirements Document

## 1. Project Overview

### Product Name

Campus Compass

### Product Description

Campus Compass is a full-stack web application designed to help students, faculty, and visitors navigate university campuses. The platform provides interactive campus maps, searchable building directories, location details, and personalized features such as favorite locations.

____________

## 2. Problem Statement

University campuses can be difficult to navigate, especially for new students and visitors. Existing campus maps are often static, difficult to search, and lack modern navigation features.

Campus Compass aims to provide a user-friendly platform that improves campus navigation and accessibility.

____________

## 8. Success Criteria

The project is considered successful when:

* Users can register using a university email and log in.
* Visitors can access campus maps without creating an account.
* Buildings can be searched and viewed.
* Campus locations are displayed on an interactive map.
* Administrators can manage campus data.
* The application is deployed and publicly accessible.
